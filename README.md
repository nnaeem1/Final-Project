# CampusLife - Mind & Schedule Tracker

## What is this?
CampusLife is a web app for college students to track their mood, write journal entries, manage tasks, and view their weekly schedule.

## Live Demo
https://nnaeem1.github.io/final-project/

## Features
- Journal with mood selector (😊 😐 😢 😡 😴)
- Journal entries save automatically in your browser
- Task list with progress bar
- Tasks save even after you refresh
- Live weather for Chicago
- Random motivational quotes from an API
- Three pages: Home, Tasks, Schedule

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Open-Meteo Weather API
- ZenQuotes API
- localStorage

## How to Use
1. Home page: Pick your mood, write a journal entry about how you day has been or anything in general, click Save
2. Tasks page: Add tasks, check them off, watch progress bar fill up!
3. Schedule page: View your weekly class schedule
